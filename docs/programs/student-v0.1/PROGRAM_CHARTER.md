# Learn-it Student V0.1 — Program Charter

## Goal

Produce one exact learner candidate that can support a real 30–45 minute learning
journey and be presented to students after a human readiness gate.

## Durable-state rule

Git artifacts are durable truth; chats are disposable workers.

## Target student journey

Discover/explain → visual support → active recall → associate → order → classify
→ practice → feedback → validate/transfer → close/resume.

## Program rules

- max 3 implementation workers in parallel;
- same exact base per wave;
- disjoint writable scopes;
- separate non-repairing integrator at every fan-in;
- exact base/result SHAs, changed paths, tests, limitations and rollback from every job;
- Knowledge is outside the critical path;
- architecture and final student-readiness require human gates.

## Gates

G0 architecture human acceptance.
G1 Wave 1 role outputs reviewed.
G2 Fan-in A exact head green.
G3 Wave 2 outputs reviewed.
G4 Fan-in B exact candidate qualified.
G5 human replay/student-readiness PASS.
Only then start the first 5–6 student sessions.
